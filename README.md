# Bemol – Jazz Club Landing Page

A sophisticated landing page for **Bemol**, a fictional live jazz club designed around an intimate atmosphere, live performances, and an elegant musical experience.

The website combines a dark visual aesthetic, warm lighting effects, refined typography, and interactive musical elements.

## Overview

Bemol is a conceptual jazz club website that allows visitors to explore upcoming performances, interact with a virtual piano, browse the menu, and make a table reservation.

The project focuses on creating an immersive digital experience inspired by classic jazz clubs and live music venues.

## Features

- **Elegant Design** – Dark aesthetic with atmospheric lighting and refined typography.
- **Dark & Light Mode** – Switch between two visual themes.
- **Live Concert Schedule** – Browse weekly performances and upcoming events.
- **Concert Countdown** – Displays the time remaining until the next performance.
- **Interactive Virtual Piano** – Play musical notes using your mouse, touch, or keyboard.
- **Jazz Demo** – Listen to a predefined musical phrase.
- **Recording Feature** – Record and replay piano performances.
- **Digital Menu** – Browse cocktails, wines, and snacks.
- **Reservation System** – Select a date, concert, seating area, and number of guests.
- **Opening Hours** – Displays the club's weekly schedule.
- **Animated Visual Effects** – Atmospheric backgrounds, transitions, and interactive details.
- **Responsive Layout** – Optimized for desktop, tablet, and mobile devices.

   ```bash

   ```

3. Make sure all three files are in the same directory.

4. Launch `index.html` in your browser or use the Live Server extension in Visual Studio Code.

This project was created to improve front-end development skills, with a focus on interactive JavaScript features, audio functionality, responsive layouts, animations, and modern UI/UX design.

## Disclaimer

Bemol is a fictional jazz club created for portfolio and demonstration purposes. Concert schedules, venue details, contact information, and reservation data are illustrative examples. The reservation form is a front-end demonstration and does not represent a real booking service.
